Mandate: Adena session test

One question: can a web page ask the Adena wallet to create a session for someone else's key? Mandate needs exactly that.

Test GNOT on the Onyx test network only. This page talks to Adena on chain onyx-1 and reads from https://rpc.onyx.testnets.gno.land:443. It never asks for a password or a seed phrase, loads nothing from the internet, and stores nothing. The test key it generates is thrown away: its private half is never shown or kept, so the session it creates can never be used. The spend limit is 0.001 GNOT and the session expires after 10 minutes, and you revoke it at the end. Each of the two transactions costs a fee of 0.01 GNOT by default (editable below).

What to do

  1. Use a browser with the Adena extension, unlocked, with an account that has a little test GNOT on Onyx (the Onyx faucet gives some).
  2. Press Connect and approve in Adena.
  3. Press Show account and network. If the network is not onyx-1, press Switch to onyx-1.
  4. Press New test key, then Create test session, and approve the transaction in Adena (it costs a small fee).
  5. Press List my sessions: the test session's address should be there.
  6. Press Revoke test session and approve, then List my sessions again: it should be gone.
  7. Press Copy everything at the bottom and paste it back to whoever asked you to run this.

The page sends these two values to Adena with the request. Adena does not estimate gas for session transactions: without them it uses 2,000,000,000 gas for a 0.1 GNOT fee, which the chain refuses. Before sending, the page reads Onyx's current gas price and refuses a fee below the minimum (fee ÷ gas wanted must be at least the gas price).
